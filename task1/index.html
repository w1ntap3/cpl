C Programming Language

C is a general-purpose, compiled language created by Dennis Ritchie at Bell Labs in 1972. It remains one of the most widely used and influential languages in software history.

Hello, World!

#include <stdio.h>

int main(void) {
    printf("Hello, World!\n");
    return 0;
}

Why Learn C?

  • Foundation for many modern languages (C++, Java, Python)
  • Direct memory control and high performance
  • Used in operating systems, embedded systems, and more
